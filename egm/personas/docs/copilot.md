## The core loop

1. `/egm-brainstorm <idea>` — the Elephant interviews you, reviewers attack the
   concept, result lands in `concepts_brief.md`.
2. `/egm-draft` — section-by-section design doc, `design_draft.md`.
3. `/egm-review <path>` — staged zero-context Goldfish review, reports written
   beside the draft.
4. `/egm-resolve` — work the findings into agreed edits.
5. Implement from the approved document. `/egm-drift-report` later compares code
   against the document.

`/egm-bootstrap` writes README contracts for an existing tree, and
`/egm-review-loop` runs a configured reviewer group without the staged flow.

## Why this maps onto Copilot

- **Fresh context.** A Copilot subagent does not inherit the parent transcript,
  which is exactly the Goldfish isolation requirement. Never paste chat history
  into a reviewer prompt; that destroys the method.
- **Named agents.** `C:/Users/schmo/.copilot/agents/egm-*.agent.md` register the reviewer personas, so
  the main chat can ask for `egm-zoom-out` and friends by name.
- **Read-only reviewers.** Reviewer adapters set `tools: ["read", "search"]`, so
  they cannot edit files or run commands.
- **Single-question gates.** Copilot has no structured question tool here, so a
  gate is one plain-text question with numbered options, then end the turn.
- **No `/egm:` prefix.** Skills are `/egm-brainstorm`, `/egm-draft`, `/egm-review`.

## Two adjustments the installer makes

1. **Direct dispatch by default.** Copilot subagents cannot spawn subagents, so
   the main chat dispatches reviewers in parallel and writes the combined report
   itself. `egm-synthesizer` stays registered for single-hop use.
2. **Skills are manual.** `disable-model-invocation: true` is preserved so Copilot
   does not start a design review mid-task. Re-run with `--auto-invoke` to drop it.

## First run after installing

Skill and agent discovery happens at chat start. Open a new Copilot Chat session
before using `/egm-*` for the first time, and enable both **Agent Mode** and
**Enable Skills** (Settings > Tools > GitHub Copilot > Customizations). Enable
the `runSubagent` tool in the tools picker, otherwise reviewers cannot be called.

Cost note: one `/egm-review` fans out to 5-16 reviewer subagents. That is the
intended shape, not a bug. `Feature spec only` and `Implementation plan only`
presets are the cheap options.
